## 4. Hai PDF xác thực

Cả hai ghi ngày 2026-10-14, tên gốc là file .md, kiến trúc Pure BFF (Pattern 2). Chung: trình duyệt không giữ JWT trong LocalStorage, SessionStorage hay biến JS, chỉ giữ cookie IAM_Session (HttpOnly; Secure; SameSite=Lax) chứa SessionId dạng s:<guid>. JWT và refresh token nằm trong Redis (TTL 2,592,000 giây tức 30 ngày, sliding). API Gateway (YARP, cổng 5273) tra cache RAM 60 giây, nếu miss thì gọi IAM Service (cổng 5290) resolve từ Redis, kiểm chữ ký JWT rồi chèn header X-User-Id, X-User-Roles, X-Session-Id trước khi chuyển tiếp. Đăng xuất xóa key Redis, dùng lại cookie cũ thì Gateway trả 401. Body phản hồi đăng nhập không được chứa accessToken hay refreshToken.

singpass_authentication_flow.pdf (Parent):
- Bốn giai đoạn: bắt tay Singpass qua MockPass (cổng 5156), JIT provisioning và cấp phiên, gọi API nghiệp vụ với header injection, đăng xuất tức thì.
- JIT: lần đầu đăng nhập, IAM tạo user theo NRIC và gán role PARENT.
