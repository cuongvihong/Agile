# UI Automation Master + 6 Session Prompts

This package contains the complete prompt set for building the course UI automation project.

## Files

1. `MASTER_PROMPT.md`
   - Overall project context
   - Architecture
   - Rules
   - Deliverables
   - Six-session workflow

2. `SESSION_01_ANALYSIS_AND_REQUIREMENTS.md`
   - Inspect HTML
   - Identify requirements
   - Build test scenarios

3. `SESSION_02_PROJECT_STRUCTURE_AND_SETUP.md`
   - Create project structure
   - Configure Pytest/Playwright
   - Set up fixtures and dependencies

4. `SESSION_03_PAGE_OBJECT_AND_LOCATORS.md`
   - Build BasePage
   - Build FormPage
   - Implement locator strategy

5. `SESSION_04_TEST_IMPLEMENTATION.md`
   - Test data
   - Test cases
   - Parametrization
   - Assertions

6. `SESSION_05_EXECUTION_DEBUGGING_AND_ARTIFACTS.md`
   - Execute tests
   - Debug failures
   - Generate screenshots, traces, and report

7. `SESSION_06_FINAL_REVIEW_AND_DELIVERABLES.md`
   - Final architecture review
   - Final execution
   - Submission preparation

## How to use

Give the AI the Master Prompt first.

Then run Session 01 → Session 02 → Session 03 → Session 04 → Session 05 → Session 06.

Each session is designed to continue from the existing project rather than recreate it.
